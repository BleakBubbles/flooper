# Decision records

Short notes on decisions that had real alternatives, written when they were made.
They record _why_, so that future-you (or a contributor) doesn't have to guess,
and can tell when the reasons no longer apply.

Format: context → decision → consequences. Never rewrite an old record; if a
decision changes, add a new record that supersedes it.
